# Flex 14

A 14-day flexibility plan with a guided breathing timer for 9 stretches.

## Put it on GitHub Pages
1. Create a new repository and upload everything in this folder to the repository root.
2. In the repository, open Settings, then Pages, choose the `main` branch and the `/ (root)` folder, and save.
3. After a minute the app is live at `https://<your-username>.github.io/<repo-name>/`.

## Install on iPhone
Open the link in Safari, tap Share, then Add to Home Screen.
